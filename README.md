# 拾光 · 明信片风格工坊

把一张照片变成不同风格的明信片：拾光治愈版使用白色手绘符号与深色铅字；第二世界把照片底部自然溶进纸面，长出 3:4 的黑线平行世界；记忆档案完整保留原照片，并在另一侧生成一页带水彩、手写标题、三枚色块和空白日记线的双联档案。整个排版与纹理渲染都在浏览器里完成，照片不会上传。

## 在线地址

<https://9heqingli.github.io/shiguang-postcard/>

由 GitHub Pages 托管，照片仍只在访问者的浏览器里处理。

## 启动

双击 `start.cmd`，或在这个目录运行：

```bash
node server.mjs
```

然后打开 <http://localhost:4173>。

需要 Node.js 18+，不需要安装依赖。

## 能做什么

- 上传、拖入、粘贴，或直接调用手机相机拍照。
- 在「拾光治愈」「第二世界」「记忆档案」三种风格间随时切换。
- 自动判断横竖构图，选择上图下文 / 左图右文。
- 在本地做轻量视觉分析：主色调、明暗、绿意、天空、水面、人物、室内等，再从照片里拾取 4–6 枚视觉取样。
- 最多 8 枚手绘符号，可取消、重抽，也可以从符号库手动补上画面里真实存在的元素。
- 第二世界会从水面、海岸、山脊、街道、室内、人物或夜色中选一个结构，延展成黑线互动场景，并生成英文旁白。
- 记忆档案按原图方向生成上下或左右双联，保留照片像素，并从照片色彩中提取三枚水彩色块。
- 五种纸张、十种铅字墨色（含黛紫、石青等中国传统色）、标题/副题/地点/日期可改。
- 2× 高清 PNG 导出（长边 2400–4000 px，风格不同尺寸不同）。
- 一键复制对应风格的图像生成 Prompt。

## 关于「识别」

没有联网模型。符号来自浏览器内的颜色分块、边缘显著性、形状与场景启发式，所以它更像一个「视觉取样器」，不是语义识别。自动结果不满意时，用「符号库」替换成照片里真实存在的东西即可。

## 隐私

照片只在内存和 Canvas 里处理，不会发送到任何服务器。刷新页面即清空。
